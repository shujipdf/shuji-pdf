Shuji PDF — Windows releases

Shuji PDF turns a PDF drawing into an editable CAD file (DXF) on your own PC — nothing is uploaded.

Download

Get the latest build from the Releases section (right side of this page) →
ShujiPDF-win64.zip → unzip anywhere → run Shuji PDF.exe. No installer, no registry entries.

What the licence unlocks

Reading, printing, PDF to Word, tables to Excel/CSV, merge PDFs and page extraction are free
(no key, no account, no upload). Only Convert to CAD needs a licence key: one-time purchase,
up to 3 computers, offline after a single online check.

Requirements

Windows 10 / 11 (64-bit). Portable: nothing is installed.
